# Python 同心圆环光栅工程阶段A

- 日期：2026-09-04
- 来源：用户阶段A要求与本地 `Circular_Grating_Model` 实现
- 适用范围：Python 实体三维模型的工程初始化阶段

## 范围

阶段A只定义独立 Python 子工程的目录、参数注册表和参数校验，不生成实体网格、可视化窗口、动画或 STL 文件。圆光栅在本项目中表示同心圆环结构，而不是径向辐条结构。

## 目录与接口

`Circular_Grating_Model/main.py` 是阶段A入口；`config/parameter.py` 提供不可变的 `CircularGratingParameters` 数据类、默认参数、范围校验、相对位移计算和 JSON 导出接口。`model/`、`visualization/`、`export/`、`tests/`、`data/` 预留给后续阶段，当前仅保留目录标记文件。

## 默认参数约定

长度统一使用 SI 单位 m，角度使用 rad。默认外半径 `R=1e-3 m`、径向周期 `P=20e-6 m`、环数 `N=50`；沟槽高度 `1e-6 m`、基体厚度 `0.2e-3 m`。主、参考光栅采用三维笛卡尔平移向量，默认参考光栅沿 x 方向偏移 `5e-6 m`。`R`、`P`、`N`允许独立调节，模型不强制三者满足整周期关系。

## 后续边界

下一阶段才实现极坐标圆环表面、封闭实体 mesh 与装配显示。Python 几何输出未来通过参数/数据文件与 MATLAB 信号仿真端交换；阶段A不宣称任何实测性能。

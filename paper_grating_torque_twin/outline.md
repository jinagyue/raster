# 论文大纲与写作策略

## 1. 建议题名

**光栅扭矩测量全链路数字孪生与算法评估**

题名控制在 25 字以内，突出测量对象、技术主线和验证任务，不把 GUI 或专利名称写进题名。

## 2. 文章定位

- 文章类型：工程研究型论文，以机理建模、数值实验和可复现软件闭环为主体。
- 目标方向：光电精密测量、智能仪器、传感器数字孪生、信号解调。
- 目标期刊路线：首选《电子测量技术》这类强调电子测量、传感器、数据采集、信号处理和精密测量的工程技术期刊；《电子测量与仪器学报》可作为提高目标，但需要补充真实实验、重复性和统计证据；《仪器仪表学报》属于更高门槛的冲刺目标，不建议在当前仅有仿真证据时直接投稿。
- 推荐论证脊柱：

  > 在光栅扭矩测量链存在机械参数漂移和光电非理想误差时，传统单一算法或离线标定难以同时覆盖多工况比较与温度补偿；本文建立带参数来源标记的全链路数字孪生模型，以 14 类可复现工况比较 5 种解调方法，并在仿真模型内验证温度前馈逆模型的误差抑制能力，结论限定在当前 `simulation/default` 参数和模型范围内。

## 3. 章节职责

### 引言

1. 说明光栅扭矩测量中的机械-光学-电信号耦合问题。
2. 指出已有研究常见的两个不足：验证链条分散、非理想工况和温漂通常分开处理。
3. 明确本文不声称完成实物标定，而是建立可复现的仿真基准和软件闭环。
4. 给出三项工作：全链路模型、算法基准、温度补偿与证据边界管理。

### 1 全链路数字孪生模型

1. 平台架构：Python/VTK 结构层，MATLAB 信号与实验层。
2. 力学映射：`T -> theta -> x_rel -> phi`。
3. 四相光电信号、误差注入、ADC 量化。
4. 11 字节旧版串口帧和软件闭环边界。

### 2 解调算法与评价指标

1. 五通道零位/四相仿真基线的 1/4、1/16、1/32 计数细分。
2. 差分 `atan2` 基线。
3. 中值去偏、RMS 归一化和二维协方差白化的改进算法。
4. RMSE、MAE、最大误差、分辨率和归一化鲁棒性评分。

### 3 仿真设计

1. 14 类工况：理想、幅值失配、相位误差、直流偏置、SNR=30/20/10 dB 和 -8/-4/-1/0/+1/+4/+8 N.m 扭矩扫描。
2. 统一样本数、时长、随机种子和参数来源标记。
3. 温度工况：-20、0、20、40、60、80 degC；补偿开关对照。
4. 数据文件、绘图文件和报告文件的可追溯关系。

### 4 结果与讨论

1. 五种解调算法的全工况统计。
2. SNR 降低和反向扭矩下的误差差异。
3. 零扭矩静态点的秩亏警告及其工程含义。
4. 温度敏感度和补偿前后误差。
5. 软件闭环验收能证明什么，不能证明什么。

### 5 局限性与后续工作

1. 参数均为仿真默认值，尚无材料和机构实测标定。
2. 温度系数为一阶线性假设，未覆盖热滞后、热梯度和装配应力。
3. 真实硬件 COM、旋转扭矩台和重复性实验尚未闭环。
4. 下一步补充实测数据、重复试验、误差预算和硬件在环验证。

### 6 结论

只总结已被当前数据支持的结论，避免把仿真精确到机器精度误写成实物测量精度。

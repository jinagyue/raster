赤峰学院学报（自然科学版）LaTeX模板说明
====================================

1. 编译方式
   推荐使用 XeLaTeX。
   若使用参考文献：
   XeLaTeX -> BibTeX -> XeLaTeX -> XeLaTeX

2. 本模板依据用户上传的《赤峰学院学报（自然科学版）规范格式论文模板》整理，
   主要复现“结构规范”和“投稿内容要求”，包括：
   - 中文标题不超过25字
   - 中文摘要不少于300字
   - 关键词3～8个
   - 中图分类号
   - 中英文题名、作者、单位、摘要和关键词
   - 引言不编号
   - 正文标题一般到三级
   - 公式全文连续编号
   - 图片中英文双语图题
   - 三线表及中英文表题
   - 结论编号
   - 顺序编码制参考文献
   - 收稿日期、基金项目、作者简介、通信作者信息

3. 重要说明
   原始PDF没有明确给出完整的版心尺寸、页边距、正文确切字号、行距、
   各级标题字体字号、最终双栏/单栏出版参数等完整排版数值。
   因此本LaTeX模板采用了适合投稿初稿的通用A4单栏排版，
   不能声称与编辑部Word模板做到像素级一致。
   投稿前建议把最终稿再按编辑部最新Word模板核对一次。

4. 图片
   尽量使用PDF/EPS等矢量图，不使用截图。
   黑白打印环境下应使用线型、点型等进行区分，不要只依赖颜色。
   坐标轴写作“量/单位”，例如 R/(mm/a)。

5. 表格
   使用 booktabs 三线表，不使用竖线、彩色底纹或截图。

6. 参考文献
   PDF要求为顺序编码制并采用方括号上标。
   references.bib 中仅给出示例。
   若需要严格按GB/T 7714自动排版，可进一步改用 biblatex-gb7714-2015。
